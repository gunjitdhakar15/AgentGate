DEFENSE IN DEPTH

Multi-Tiered Security Pipeline

Every single agent tool invocation passes through five layers of evaluation before any tool execution occurs.

LAYER 01

Rate Limiting (Token Bucket)

Enforces strict per-tool call quotas and concurrency controls. Eliminates runaway recursive agent loops and high-velocity brute-force calls.

burst: 5 / window: 1m
LAYER 02

Tier 0 Static Policy Engine

Deny-by-default whitelisting with argument regex matching, path restrictions, and forbidden parameter patterns checked with zero network latency.

latency < 0.38ms
LAYER 03

Zero-Leak Secret Redaction

Scrubs API keys (sk-...), bearer tokens, passwords, and private headers from inbound arguments and outbound tool responses before persistence.

scrubbing: 100% complete
LAYER 04

Tier 1 Semantic LLM Judge

Bridges the "semantic gap" that regex misses. Evaluates intent using Claude Haiku, GPT-4o-mini, Gemini Flash, or local Ollama with anchored scoring.

providers: anthropic | openai | gemini | ollama
LAYER 05

Human-In-The-Loop (HITL)

Consequential gray-zone actions [0.4, 0.8) suspend tool execution and alert the operator via Web Cockpit or CLI for real-time approval.
