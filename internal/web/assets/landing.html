What the guard checks

Four layers of protection run on every single tool call — before it ever reaches a real tool.

📜

Policy enforcement

Deny-by-default whitelisting, per-tool rules, and argument patterns that hard-block rm -rf style commands — even when the tool itself is allowed.

🕶️

Secret redaction

API keys, tokens, and passwords are masked to *** in arguments and responses — including deeply nested JSON — so they never touch logs or the agent view.

⏱️

Rate limiting

Token-bucket limits per tool (e.g. 5 shell calls a minute) stop runaway loops and hijacked prompts from hammering your systems.

📹

Audit logging

Every request, response, and block lands in a replayable JSONL log with secrets already stripped. Replay any incident like a security camera.

How it works

A transparent man-in-the-middle: your agent talks to the real tool server, and never notices a thing.

Install in 60 seconds

Runs anywhere — your laptop, a server, or a container. No runtime required: one binary.

Option 1 — Download a binary

Grab the latest release for your OS:

Windows · Linux · macOS (Apple Silicon) · macOS (Intel)

Rename it to agentgate, run ./agentgate -h to verify.

Point your MCP client at it instead of the real tool server — nothing else changes.

Option 2 — From source (Go)

Install with Go: go install github.com/gunjitdhakar15/AgentGate/cmd/agentgate@latest

Or build from the repo: git clone it and run go build -o agentgate ./cmd/agentgate.

Try the one-command demo: powershell -ExecutionPolicy Bypass -File scripts\demo.ps1 (Windows) — it starts the firewall, feeds it a scripted agent session, and opens the live dashboard.

Quickstart

Wrap any MCP stdio server — like the official filesystem server — and define your policy.

# 1. Wrap any MCP stdio tool server
agentgate -config gate.yaml

# 2. Open the live dashboard
agentgate -config gate.yaml -serve :8700      # dashboard on http://localhost:8700

# 3. Or run dashboard-only against an existing audit log
agentgate -serve :8700 -audit gate.jsonl

Example policy file:

tool_server:
  command: npx
  args: ["-y", "@modelcontextprotocol/server-filesystem", "/tmp"]

policy:
  tool_rules:
    - apply_to: "*"            # deny everything first...
      deny: true
    - apply_to: read_file      # ...then whitelist what you trust
      allow: true
    - apply_to: shell
      allow: true
      arg_deny_pattern: "(rm -rf|del /s|format |shutdown)"
  redact:
    - keys: ["api_key", "password", "token"]
      pattern: ".*"
      replacement: "***"
  rate_limits:
    - apply_to: shell
      burst: 5
      window: 1m
